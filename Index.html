Our History

The festival started in December 2015 with 8 events and 300 participants. Today it hosts 25 events and more than 2,000 participants from the college and nearby institutions.

Culture is the heart of a campus, and art is its heartbeat.

— Principal, during the inaugural function.

Aim and Objectives

  • Give every student a stage, with a target of at least N = 25 events and P ≥ 2,000 participants (P/N ≈ 80 per event).
  • Keep traditional art forms such as Bharatanatyam, Karakattam and Villu Paattu alive.
  • Promote teamwork, creativity and sustainable celebration.

As our students often say, the stage belongs to everyone.

Venues

Open-Air Stage
Main stage for dance, music and the closing ceremony.
Mini Auditorium
Drama, skit and speech events with 400 seats.
Art Gallery Hall
Rangoli, painting and photography exhibitions, with CO2-free decorations made from recycled material.

Sample stage cue shown to the sound team

light.on("stage", colour="gold")
music.play("welcome-song")

What happens when a user opens this website

  1. The user types the URL into the browser (the client) and presses Enter.
  2. The browser asks a DNS resolver for the IP address of festival.example.edu.
  3. Using that IP address, the browser sends an HTTPS request (GET /index.html) to the Web server.
  4. The server finds the file and sends a response: status code 200 and the HTML document.
  5. While reading the HTML, the browser sends further requests for the CSS, images and video.
  6. The browser renders the page from the HTML, CSS and media files.

URL Analysis

Example URL: https://festival.example.edu:443/events.html?day=1#event-table

Table 3: Parts of the example URL
PartValueMeaning
SchemehttpsSecure HTTP protocol
Domain namefestival.example.eduName resolved to an IP address by DNS
Port443Default HTTPS port (optional)
Path/events.htmlFile requested on the server
Query?day=1Extra data sent to the server
Fragment#event-tableSection of the page to scroll to

Relative paths

  • images/open-air-stage.png in about.html: the browser joins it with the current folder, giving http://localhost:8000/images/open-air-stage.png.
  • contact.html#office-hours: opens contact.html in the same folder and scrolls to the element with id="office-hours".

Development Environment

Editor: Visual Studio Code. Browser: Google Chrome. Local server: Python http.server (XAMPP Apache works the same way).

cd festival-site
python -m http.server 8000
# open http://localhost:8000/index.html

After each change, I saved the file and refreshed the browser (Ctrl + R). The localhost screenshot is in the report.

Hosting Recommendation

I recommend shared hosting. The site is small and static, traffic is a few hundred visits a day before the festival, and shared hosting is the cheapest option with the least administration. A VPS or dedicated server gives more control and scalability, but the festival committee does not need it yet.

The domain name gives a readable address, DNS records (A record) point the name to the server’s IP address, the hosting server stores and serves the files, and the control panel manages files, SSL certificates and email.

Security Considerations

  • Use HTTPS so form data is encrypted in transit.
  • No passwords or secrets are placed in HTML comments or hidden inputs.
  • Browser validation (required, pattern, min/max) helps users, but the server must validate again.
  • Future database code must use parameterised queries to prevent SQL injection.
  • Uploaded files must be checked for type and size and stored outside the web root.
  • Any user input shown back on a page must be escaped to prevent XSS.
  • The form collects only the data needed for the registration.
  • The hosting account uses a strong password and two-factor authentication.
